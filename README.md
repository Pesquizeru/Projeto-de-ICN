IMPORTANTE: Para rodar o programa, escholha seu IDE de preferência, crie um projeto, e insira os arquivos na pasta /src para a pasta /src do seu projeto. Os outros arquivos não são necessários.
Lembre que o programa é escrito em java, ent seu IDE tem que ser compatível.

Esse projeto é um trabalho final para a turma 2025.2 de ICN da UFRJ. Ele implementa os métodos numéricos de Taylor, Newton, Bisseção, Interpolação Polinomial com Lagrange,
Integração numérica com trapézio (sem pensar no erro), Resolvendo equações diferenciais aproximadamente com “diferenças finitas”
